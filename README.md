## Overview

This repository contains laboratory work for **LAB 3** of the Computer Fundamentals & Career Pathways (CSE103) course at **K.R. Mangalam University**, Gurugram, Haryana.

The project demonstrates Git version control, GitHub collaboration, Python programming, and professional Markdown documentation.

## How to Run

Clone the repository:

```bash
git clone https://github.com/ralcoralson/cse103-lab-LAB3.git
```

Navigate to the project:

```bash
cd cse103-lab-LAB3
```

Run the Python script:

```bash
python3 main.py
```

## Key Learning Outcomes

- Configured Git identity and initialised local repositories.
- Created meaningful commits using Conventional Commit messages.
- Connected a local repository to GitHub.
- Pushed local commits to a remote repository.
- Pulled updates from GitHub to the local repository.
- Created structured Markdown documentation.
- Learned Markdown formatting, tables, hyperlinks, and code blocks.
