
# Markdown Syntax Guide

This guide demonstrates the basic Markdown syntax used for GitHub documentation.

## 1. Headings

# Heading 1
## Heading 2
### Heading 3

## 2. Text Formatting

**This text is bold.**

*This text is italic.*

~~This text is strikethrough.~~

## 3. Unordered Lists

- Item A
- Item B
  - Nested item B1
  - Nested item B2

## 4. Ordered Lists

1. First step
2. Second step
3. Third step

## 5. Inline Code

Use `print("Hello")` to display a message in Python.

## 6. Fenced Code Block

```python
def greet(name):
    return f"Hello, {name}!"

print(greet("Developer"))
```
